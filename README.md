# bissspixie.github.io
Project Title: Cognitive Drift
Background and Objective: In an increasingly digitized world, prolonged screen exposure and habitual media multitasking have become commonplace among students. This project investigates the relationship between habitual daily screen time and core cognitive functions, specifically visual reaction speed, short-term memory recall, and attention stability. Additionally, the study evaluates the real-time degradation of cognitive performance caused by digital distractions (Dual-Task Interference).
